# CMS Blog Management Platform

A full-featured Blog Management System built using Django, Django REST Framework, PostgreSQL, JWT Authentication, and Tailwind CSS.

This project allows users to create, manage, update, and delete blog posts with image uploads, comments, likes/unlikes, and read count tracking.

---

# Features

## Authentication & Authorization
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Only blog owners can edit/delete their blogs

---

## Blog Features
- Create Blog
- Update Blog
- Delete Blog
- Blog Detail View
- Blog List View
- Upload Blog Images
- Read Count Tracking
- Like / Unlike Blogs

---

## Comment System
- Add Comments
- Comment Approval System
- Admin Comment Moderation

---

## Search / Filtering / Pagination
- Search blogs by title/content
- Filter blogs by latest/popular
- Pagination support

---

## Frontend
- Django Template Rendering
- Tailwind CSS Styling
- Responsive UI
- Flash Messages

---

## Admin Features
- Manage Users
- Manage Blogs
- Manage Comments
- Comment Approval / Blocking
